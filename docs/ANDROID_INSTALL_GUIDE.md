## 🛠️ 分步安装教程

1. **下载安装包**
   - 在手机浏览器打开 [GitHub Releases 最新版本](https://github.com/xunrana/LNU-LibSeat-Automation/releases/latest)，点击下载 **`LNU-LibSeat-Android-arm64.apk`**（也可先在电脑下载后传到手机微信/QQ/文件管理）。
   - *提示*：若微信接收后文件名被自动追加 `.1` 后缀（如 `LNU-LibSeat-Android-arm64.apk.1`），在文件管理器里重命名去掉 `.1` 后再点击安装，或选择「用其他应用打开 → 软件包安装程序」。
2. **允许安装未知来源应用**
   - 点击 `.apk` 开始安装；若系统提示「不允许安装来自此来源的应用」，点击 **去设置 → 打开「允许来自此来源的应用」** 后返回继续安装。
   - **华为鸿蒙（HarmonyOS）**：若被「纯净模式 / 增强防护」拦截，请在弹窗底部点 **「继续安装」**，或到 **设置 ▸ 系统和更新 ▸ 纯净模式** 临时关闭增强防护后再装。
   - **小米澎湃（HyperOS / MIUI）**：若提示「未经过安全检测」，点击 **「继续安装 / 单次授权安装」**。
   - **vivo（OriginOS）/ OPPO（ColorOS）**：点击底部的 **「仍要安装 / 了解风险，继续安装」** 并输入锁屏密码确认即可。
3. **完成首次配置**
   - 打开桌面的蓝金校徽 **LNU LibSeat** 图标：
     - 切到右下角 **「我的 ▸ 校园卡账号」** 填入校园卡号与密码（初始密码一般为 `000000`）；
     - 若需全天免换座自习，可一并启用并配置副号时段；
     - 允许系统的 **通知权限**（用于常驻守夜通知、抢座成功战报与签到防违约提醒）。

## ⏰ 睡前设好次日 06:30 准点抢座：隔夜防杀与锁屏解冻指南

与 iOS 类似，现代国产 Android 12–16 系统（尤其是 **vivo OriginOS / 小米 HyperOS / 华为 HarmonyOS / OPPO ColorOS**）为了省电，在手机**锁屏 10～30 秒后**会对未加白名单的 App 触发 **Linux cgroup 墓碑冻结**，导致后台倒计时暂停。

本 App 在代码层已经内置 **5 重隔夜防杀引擎**：
1. **双闹钟系统级唤醒**：`AlarmManager.setAlarmClock`（提前 20 秒 `06:29:25` 主唤醒，与系统闹钟同级，穿透 Doze 深度休眠）+ `setExactAndAllowWhileIdle`（`06:29:45` 预热时刻第二道轻推防二次冻结）；
2. **Android 14+ 冻结态强制解冻**：闹钟触发时，即便进程处于「未死但被墓碑冻结」状态，也会自动通过 `PendingIntent`（`MODE_BACKGROUND_ACTIVITY_START_ALLOWED`）+ `CATEGORY_ALARM` 全屏锁屏唤醒通知拉起主界面并强行解冻 Dart 引擎；
3. **动态 26 小时 `PARTIAL_WAKE_LOCK` + `WifiLock`**：自动覆盖前一天晚上开启到次日 `06:50`，防止夜间 Wi-Fi 深度休眠断网；
4. **前台常驻守夜服务（`IMPORTANCE_DEFAULT` 静音通道）**：显著降低系统内存回收优先级；
5. **进程被杀自动复活 + 手机夜间重启自恢复**：`RushAlarmStore` 持久化守夜状态，夜间进程被杀由闹钟冷启动拉起续抢，手机半夜自动更新重启后由 `RushBootReceiver` 自动重挂闹钟。

> [!IMPORTANT]
> **国产 ROM 铁律**：再强的代码也必须配合**一次性开启本机「后台高耗电 / 自启动」白名单**，否则系统内核会在锁屏后直接冻结进程并压制唤醒。按下方 1 分钟配置好后，以后每天睡前只需一键点开即可直接锁屏！

### 第一步：App 内一键保活体检（全部点亮为绿色）

打开 App → **「我的 ▸ 晨约守夜与后台保活」**，将 4 项实时体检开关逐一点亮：

| 体检项 | 作用 | 操作 |
| :--- | :--- | :--- |
| **1. 电池优化白名单（无限制）** | 防止锁屏触发墓碑冻结与收回 WakeLock（**最关键**） | 点按直达弹窗选「允许」 |
| **2. 精确闹钟权限（AlarmClock）** | 允许 `06:29:25` / `06:29:45` 准点穿透休眠唤醒 | 点按开启授权 |
| **3. 系统通知权限** | 用于守夜常驻通知、准点唤醒与签到防违约提醒 | 点按允许通知 |
| **4. 锁屏全屏唤醒权限（Android 14+）** | 允许准点闹钟穿透锁屏直接拉起解冻抢座引擎 | 点按开启全屏通知授权 |

> 启动定时抢座前，如果检测到「电池优化白名单」仍未开启，首页也会主动弹窗提醒你一键去开启，避免白等一晚。

### 第二步：按手机品牌开启专属 4 项（一次性设置）

在「晨约守夜与后台保活」页点击最下方的 **「vivo / 小米 / 华为 / OPPO 专属保活项」** 可直达系统应用信息页，然后按你的手机品牌对照勾选：

#### 1. vivo / iQOO（OriginOS 4 / Android 14 真机实测路径）
1. **允许后台高耗电（最关键）**：`设置 ▸ 电池 ▸ 后台耗电管理 ▸ LNU LibSeat ▸ 允许后台高耗电`（同时确认关闭「省电模式」与「睡眠模式」）。
2. **自启动 + 后台弹出界面 + 锁屏显示**：`设置 ▸ 应用与权限 ▸ 应用管理 ▸ LNU LibSeat ▸ 权限（所有权限）` → 全部打开 **「自启动」**、**「后台弹出界面」**、**「锁屏显示」**。
3. **关闭自动休眠**：同级应用信息页如有 **「暂停未使用应用的活动」**，请关闭。
4. **多任务卡片加锁**：底部上滑停顿打开最近任务 → 点击本 App 卡片右上角小箭头（或长按卡片）→ 点 **「锁定」**。

#### 2. 小米 / Redmi（HyperOS 澎湃 OS / MIUI）
1. **省电策略无限制**：`设置 ▸ 应用设置 ▸ 应用管理 ▸ LNU LibSeat ▸ 省电策略 ▸ 无限制`。
2. **自启动 + 后台弹出 + 锁屏显示**：同页打开 **「自启动」**；进入 **「其他权限」** 打开 **「后台弹出界面」** 与 **「锁屏显示」**。
3. **多任务卡片加锁**：最近任务长按本 App 卡片 → 点小锁图标 **锁定**。

#### 3. 华为 / 荣耀（HarmonyOS / MagicOS）
1. **关闭自动管理**：`设置 ▸ 应用和服务 ▸ 应用启动管理 ▸ LNU LibSeat` → 关闭「自动管理」，在弹窗中**全部勾选**「允许自启动」「允许关联启动」「允许后台活动」。
2. **忽略电池优化**：`设置 ▸ 应用和服务 ▸ 权限管理 / 特殊访问权限 ▸ 电池优化` → 切到「所有应用」→ 找到 `LNU LibSeat` 设为 **「不允许」**（即不优化）。
3. **多任务下拉加锁**：进入最近任务，将本 App 卡片**向下轻拉**看到左上角出现小锁图标即锁定成功。

#### 4. OPPO / 一加 / 真我（ColorOS）
1. **完全允许后台行为**：`设置 ▸ 应用 ▸ 应用管理 ▸ LNU LibSeat ▸ 耗电管理` → 开启 **「允许完全后台行为」** 与 **「允许应用自启动」**（如有「允许后台高耗电」一并打开）。
2. **悬浮窗 / 后台弹出**：`权限管理` 中开启通知与锁屏显示。
3. **多任务卡片加锁**：最近任务点击本 App 卡片右上角 `⋮` → 点 **「锁定」**。

## 🛟 常见问题排查（FAQ）

<details>
<summary><b>Q1: 为什么我以前按电源键锁屏后，倒计时就暂停了，直到解锁打开 App 才突然开跑？</b></summary>

这就是国产 Android 14（特别是 vivo OriginOS / 小米 HyperOS）的**后台墓碑冻结**导致的典型症状：未开启「允许后台高耗电 / 电池优化白名单」时，系统锁屏几秒就会把进程冻结。请确保已升级到最新版 `LNU-LibSeat-Android-arm64.apk`，并按上文完成 **「App 内 4 项保活体检 + 对应品牌专属 4 项」**，再用 2 分钟自测验证即可解决。
</details>

<details>
<summary><b>Q2: 为什么 Android 安装包有约 165 MB？</b></summary>

为了实现 **100% 离线、零云端打码费、识别率与电脑桌面端完全一致**，安装包内完整打包了 **5 个原版无损 ONNX 神经网络模型**（总计 `159.52 MB`，包括登录 4 位 OCR、Click1/Click3 YOLOv8 目标检测与 MobileNetV4 Siamese 孪生匹配网络）以及 ARM64 原生 ONNX Runtime 推理库。App 本体代码仅占约 6 MB。
</details>

<details>
<summary><b>Q3: 预约成功后的「签到防违约提醒」在划掉 App 后还会响吗？</b></summary>

**会！** 预约成功后（或进入「入馆」页刷新同步预约时），App 会通过 Android 系统级 `AlarmManager` + `CheckinReminderReceiver` 自动注册「预约开始前 15 分钟温和提醒」和「开始后 20 分钟（距 30 分钟违约截止仅剩 10 分钟）紧急防违约闹钟」。即便锁屏或把 App 从后台划掉，到点仍会震动弹窗提醒（需已授予系统通知与精确闹钟权限）。
</details>

<summary><b>Q5: 手机锁屏/后台运行时验证码识别会因为没有 GPU 而报错吗？</b></summary>
