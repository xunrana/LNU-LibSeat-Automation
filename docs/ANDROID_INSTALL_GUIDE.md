# Android 安装与 06:30 防杀后台教程

适用于 **Android 7.0 及以上（64 位 ARM64）** 的安卓和鸿蒙手机（已在 Android 14 / vivo OriginOS 4 真机实测通过）。不需要电脑，不需要 Root，装好后永久有效，没有 iOS 那种 7 天续签限制。

## 一、下载与安装

1. 用手机浏览器打开 [GitHub Releases](https://github.com/xunrana/LNU-LibSeat-Automation/releases/latest)，下载 **`LNU-LibSeat-Android-arm64.apk`**（约 166 MB，内置全部 5 个本地 ONNX 识图模型；本地用 `python build_android.py` 打包出来的 `dist/辽宁大学图书馆座位预约.apk` 是同一个包）。
   - 如果用微信传到手机，文件名末尾可能被自动加上 `.1`，在文件管理器里删掉 `.1` 再点安装就行。
2. 直接点击安装。因为是免费开源软件、没花钱去各大应用商店备案，系统会弹常规安全提示，放行即可：
   - **华为鸿蒙（HarmonyOS）**：弹窗底部点 **继续安装**；若被纯净模式增强防护拦截，去 **设置 → 系统和更新 → 纯净模式** 临时关闭后再装。
   - **小米澎湃（HyperOS / MIUI）**：点 **继续安装 / 单次授权安装**。
   - **vivo（OriginOS）/ OPPO（ColorOS）**：点 **仍要安装 / 了解风险，继续安装** 并输入锁屏密码确认。
3. 装好后打开桌面 **LNU LibSeat**：
   - 切到 **我的 → 校园卡账号** 填学号和密码（初始密码一般为 `000000`），双号全天自习可顺手把副号也填上；
   - 允许 **系统通知权限**（守夜常驻通知、抢座成功提醒和防违约签到闹钟都依赖它）。

## 二、睡前设好 06:30：为什么锁屏会被冻结，怎么解决？

现在的国产 Android 12–16 系统（尤其是 vivo OriginOS、小米 HyperOS、华为鸿蒙、OPPO ColorOS）为了省电，在手机**锁屏 10–30 秒后**就会把未加白名单的 App 直接用内核冻结，导致倒计时卡住、直到早上解锁打开 App 才突然开始跑。

App 代码里已经尽量做好了底层防杀：
- **`MediaSession` + 实时流不可闻音频轨（核心）**：定时启动时同步挂起 `mediaPlayback|specialUse` 前台服务，注册正式系统 `MediaSession`（`STATE_PLAYING`）与 `Notification.MediaStyle` 实时倒计时通知，并用 `AudioTrack MODE_STREAM` 持续写入 24kHz / -90 dB 超声微幅 PCM（物理上绝对听不到、不申请音频焦点、不打断抖音/音乐声音，抢完立刻释放）。相比静态全零静音，这种实时活跃媒体流不会被 vivo PEM / 小米 Millet / OPPO Hans 识别为空壳冻结；
- **原生 Kotlin 心跳 + 通知栏实时走秒**：前台服务内自带独立原生心跳，每秒刷新通知栏真实倒计时（切去刷抖音下拉通知栏就能直接看到是不是在实时走秒），并在开抢前 60 秒以 250ms 频率主动向 Dart 推送唤醒信号，彻底摆脱 Flutter 后台 `Timer` 休眠限制；
- **动态 `WakeLock` + `WifiLock`**：覆盖到开抢后 20 分钟（最长 26 小时），防夜间 Wi-Fi 深度休眠断网；
- **四段式系统硬件闹钟 + 7.5 秒广播租约**：分别在 `06:29:25`、`06:29:45`、`06:29:55` 和 `06:29:59` 触发四道闹钟，并通过 `goAsync()` 持有 7.5 秒活跃租约确保 Dart 线程拿到完整 CPU 时间片；息屏态自动亮屏拉起主界面，夜间被杀或重启也能自动续抢。

**但光靠代码绕不过国产 ROM 的硬限制——你必须在手机系统里给一次后台白名单。** 下面两步只需要做一次，以后每天睡前点开就能直接锁屏：

### 第 1 步：先把 App 里的 4 项体检全部点绿

打开 App → **我的 → 晨约守夜与后台保活**，把页面上 4 项实时状态逐一点开授权：

| 体检项 | 作用 |
| :--- | :--- |
| **1. 电池优化白名单（无限制）** | **最关键**，防止锁屏触发系统冻结和收回唤醒锁 |
| **2. 精确闹钟权限（AlarmClock）** | 允许四段式闹钟（`06:29:25 / 06:29:45 / 06:29:55 / 06:29:59`）准时穿透休眠触发 |
| **3. 系统通知权限** | 显示守夜常驻通知、准点唤醒与签到防违约闹钟 |
| **4. 锁屏全屏唤醒权限（Android 14+）** | 允许到点时穿透锁屏直接拉起解冻抢座引擎 |

> 启动定时前如果检测到电池优化白名单还没开，首页也会弹窗提示你去开。

### 第 2 步：按手机品牌开一下专属权限（一次性）

在「晨约守夜与后台保活」页面最底部点 **vivo / 小米 / 华为 / OPPO 专属保活项** 可直接跳到系统应用信息页，按品牌对照打开：

**vivo / iQOO（OriginOS 4 / Android 14 真机实测）**
1. **允许后台高耗电（最重要）**：`设置 → 电池 → 后台耗电管理 → LNU LibSeat → 允许后台高耗电`（同时关掉省电模式和睡眠模式）。
2. **自启动 + 后台弹出界面 + 锁屏显示**：`设置 → 应用与权限 → 应用管理 → LNU LibSeat → 权限（所有权限）`，把这三项全部打开。
3. 同级应用信息页如果看到 **暂停未使用应用的活动**，关掉它。
4. **多任务卡片加锁**：底部上滑进最近任务 → 点本 App 卡片右上角小箭头（或长按卡片）→ 点 **锁定**。

**小米 / Redmi（HyperOS / MIUI）**
1. `设置 → 应用设置 → 应用管理 → LNU LibSeat → 省电策略 → 无限制`。
2. 同页打开 **自启动**；进 **其他权限** 打开 **后台弹出界面** 和 **锁屏显示**。
3. 最近任务长按本 App 卡片点小锁图标 **锁定**。

**华为 / 荣耀（HarmonyOS / MagicOS）**
1. `设置 → 应用和服务 → 应用启动管理 → LNU LibSeat` → 关掉「自动管理」，在弹窗里**全选**允许自启动、关联启动和后台活动。
2. `设置 → 应用和服务 → 权限管理 / 特殊访问权限 → 电池优化` → 切到「所有应用」→ 找到 `LNU LibSeat` 改为 **不允许**（不优化）。
3. 最近任务把本 App 卡片**往下拉一下**看到左上角出现小锁图标即可。

**OPPO / 一加 / 真我（ColorOS）**
1. `设置 → 应用 → 应用管理 → LNU LibSeat → 耗电管理` → 打开 **允许完全后台行为** 与 **允许应用自启动**（有允许后台高耗电一并打开）。
2. `权限管理` 里开启通知与锁屏显示。
3. 最近任务点本 App 卡片右上角 `⋮` → **锁定**。

## 三、强烈建议：睡前花 2 分钟实测一次

配完上面的权限后，别等到第二天 6:30 才发现没生效，直接花 2 分钟测一下：

1. 在首页切到 **定时模式**，把时间滚轮调成 **当前时间 + 2 分钟**；
2. 点 **开启晨约**，确认日志输出了 `MediaSession+前台守夜已挂起 · 实时流防冻结=已激活(stream@...) · 闹钟=AlarmClock×4段(...) · 通知栏实时倒计时已启`，并且没有未开电池白名单的警告；
3. **直接按电源键锁屏**（或者切去刷抖音，下拉通知栏应能看到倒计时每秒实时跳动）；
4. 看提前 35 秒时手机能不能自动亮屏或在后台准点启动预热并执行。验证没问题后，把时间改回 `06:30` 就能放心睡了。

> **期末 / 考研兜底方案（夜守模式）**：如果第二天特别重要，或者你的机型后台管控极严，启动定时后点首页 **夜守** 会进入纯黑 `#000000` 极微光时钟页（每分钟微移防烧屏，阻止自动息屏）。**插着充电线放床头、别按电源键锁屏**，App 一直在前台运行，绝对不会被系统冻住。

## 四、常见问题

<details>
<summary><b>Q1: 为什么安装包有 166 MB？</b></summary>

为了不依赖任何服务器、不花钱买打码 API，且保证和电脑端一样的识别率，APK 里直接打包了 5 个原版无损 ONNX 模型（共约 159.5 MB）和 ARM64 原生 ONNX Runtime 库，App 自身代码只有约 6 MB。
</details>

<details>
<summary><b>Q2: 预约成功后的签到提醒，把 App 从后台划掉还会响吗？</b></summary>

会。约座成功后（或进「入馆」页刷新时），App 会通过 Android 系统闹钟注册两条提醒：预约开始前 15 分钟温和提醒、开始后 20 分钟（距 30 分钟违约截止仅剩 10 分钟）紧急提醒。只要授予了通知和精确闹钟权限，划掉后台或锁屏到点都会弹窗震动。
</details>

<details>
<summary><b>Q3: 以后更新新版 APK 会不会丢失账号和收藏的座位？</b></summary>

不会。不要先卸载旧版，直接下载新版 `LNU-LibSeat-Android-arm64.apk` **覆盖安装**即可，校园卡号、加密密码、快捷方案、备选自习室和宝藏座笔记都会原样保留。
</details>

<details>
<summary><b>Q4: 锁屏或后台运行时识别验证码会出错吗？</b></summary>

不会。Android 端专门用原生纯 CPU `BitmapFactory` 解码验证码图片，不依赖锁屏可能不可用的 GPU 渲染管线，亮屏和息屏识别表现一致。
</details>
